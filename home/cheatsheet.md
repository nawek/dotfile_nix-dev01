# Raccourcis clavier Hyprland — Kuro

## Applications
| Raccourci | Action |
|---|---|
| `Super + Entrée` | Terminal (Kitty) |
| `Super + D` | Lanceur d'apps (Rofi) |
| `Super + E` | Gestionnaire de fichiers (Nautilus) |
| `Super + L` | Verrouiller l'écran (Hyprlock) |
| `Super + X` | Menu power (wlogout) |
| `Super + N` | Panneau notifications (SwayNC) |

## Fenêtres
| Raccourci | Action |
|---|---|
| `Super + Q` | Fermer la fenêtre |
| `Super + V` | Basculer flottant |
| `Super + F` | Plein écran |
| `Super + S` | Changer orientation split |
| `Super + T` | Grouper/dégrouper (onglets) |
| `Super + Tab` | Onglet suivant dans le groupe |

## Focus / Déplacement (vim-like)
| Raccourci | Action |
|---|---|
| `Super + H/J/K/L` | Focus gauche/bas/haut/droite |
| `Super + Shift + H/J/K/L` | Déplacer fenêtre |
| `Super + Ctrl + H/L` | Focus écran gauche/droite |
| `Super + Ctrl + Shift + H/L` | Fenêtre vers autre écran |
| `Super + Alt + H/J/K/L` | Redimensionner |

## Workspaces
| Raccourci | Action |
|---|---|
| `Super + 1-9` | Aller au workspace 1-9 |
| `Super + Shift + 1-9` | Déplacer vers workspace 1-9 |
| `Super + molette` | Workspace suivant/précédent |
| Swipe 3 doigts | Changer de workspace |

## Scratchpad & Modes
| Raccourci | Action |
|---|---|
| `Super + \`` | Terminal dropdown (scratchpad) |
| `Super + R` | Mode resize (h/j/k/l, Escape pour sortir) |
| `Super + Z` | Zen mode (toggle waybar) |
| `Super + Shift + Z` | Toggle Do Not Disturb |
| `Super + F1` | Ce fichier (cheatsheet) |
